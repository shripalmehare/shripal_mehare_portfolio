# Shripal Mehare Portfolio

A clean, responsive personal portfolio website for a BBA Computer Applications student / aspiring software developer.

## Included
- Responsive HTML/CSS portfolio
- About, Skills, Projects, Education and Contact sections
- Light professional design
- Mobile-friendly layout
- LinkedIn and GitHub placeholders

## Before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

You can also replace the `SM` photo placeholder with your professional profile image.

## Deploy on Vercel
1. Create/login to https://vercel.com
2. Choose **Add New → Project**
3. Upload/import this folder or connect a GitHub repository.
4. Deploy.
5. Vercel will provide a public URL such as `your-name.vercel.app`.

## Deploy on GitHub Pages
Upload `index.html` and `style.css` to a GitHub repository, then enable GitHub Pages in the repository settings.
